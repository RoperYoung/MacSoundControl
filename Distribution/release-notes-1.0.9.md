# Mac Sound Control 1.0.9

本次正式更新集中完善首次启动、主界面、菜单栏控制与产品品牌体验。

- 手动打开应用时自动展示主界面；开机登录项启动仍保持菜单栏静默运行；
- 新增原生单页主界面、八项侧栏导航与菜单栏使用引导；
- 优化系统输出音量、静音状态、应用音量统一/分开控制与输入输出设备选择；
- 改进声音测试、电平汇总、输入源切换和输入通道重连按钮；
- 统一应用名称为 `Mac Sound Control`，换用新的产品图标，并优化 About 项目链接；
- 保持本地音频处理，不录制、不保存、不上传音频。

系统要求：macOS 14 或更高版本；分应用音量需要 macOS 15 或更高版本。

## English

This production update refines first launch, the main window, menu bar controls,
and product identity.

- Show the main window on manual launch while keeping login-item launches silent;
- Add a native single-page window with eight sidebar destinations and menu bar guidance;
- Improve system output, mute state, unified/per-app volume modes, and device selection;
- Refine input testing, live level summaries, source switching, and input reconnect controls;
- Standardize the `Mac Sound Control` name, adopt the new product icon, and improve the About project link;
- Keep all audio processing local without recording, saving, or uploading audio.

Requires macOS 14 or later. Per-application volume requires macOS 15 or later.
